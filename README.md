# M5PaperDashboard

一个基于 **M5Stack M5Paper**(540×960 竖屏电子墨水屏)的系统状态仪表盘。上位机通过 USB 串口
推送系统数据,M5Paper 将其渲染为三个铺满全屏的区块——**MEMORY / TEMPERATURE / POWER**,每个区块
包含标签、进度条和一个大号数值。**G26** 上的继电器驱动散热风扇,屏幕上的向上箭头指示是哪个指标
触发了风扇。

## 功能特性

- **三个全屏区块**,每个 540×320 px,铺满整块屏幕、不留未刷新边框,因此长时间运行也不会在边缘
  积累永久残影。
- **GC16 全灰阶刷新**(先反色再绘制)→ 残影几乎为零。
- **抗褪色**:若某区块在 `REFRESH_MAX_AGE_MS`(默认 15 分钟)内未被重绘,即使数值没变也会强制重绘
  一次——电子墨水颗粒会随时间松弛、图像逐渐发白,定期重新驱动像素可保持清晰。只有**陈旧**区块才会
  触发,频繁变化的指标永远不会触发它。
- **断连状态**:若 30 秒内没有收到数据包(或开机后首包到达之前),所有数值显示 `-`、进度条归零。
- **伪粗体文字**(内置 TTF 只有一种字重,通过在微小偏移处叠印来加粗笔画),便于一米开外也能看清。
- **滞回风扇控制**(G26),温度/功率组合触发。
- **向上箭头指示**,与风扇启停同步,绘制在高于关闭阈值的那一行(温度和/或功率)。
- **内置 SHT30**(I²C 0x44,SDA=G21 / SCL=G22),可按需上报环境温湿度。

## 硬件

| 项目 | 说明 |
|---|---|
| 主板 | M5Stack M5Paper(ESP32,IT8951 电子墨水驱动) |
| 风扇 / 继电器 | 接 **G26**。若继电器为低电平触发,把 `FAN_ACTIVE_LOW` 设为 `1`。 |
| 环境传感器 | 内置 SHT30(I²C `0x44`) |

## 串口协议

USB 串口,**115200 波特率**。

**上位机 → M5Paper**,每次更新一行(各字段可缺省、按需发送):

```
MEM:<0-100>,MEMG:<GB>,TEMP:<°C>,PWR:<watts>\n
```

- `MEM`  — 内存使用百分比(0–100),驱动 MEMORY 进度条
- `MEMG` — 已用内存(GB),作为 MEMORY 的数值显示
- `TEMP` — 温度(°C),进度条按 20 °C = 0% … 100 °C = 100% 缩放
- `PWR`  — 功率(W),进度条 = 功率(钳制到 0–100)

**环境传感器查询**——发送 `[T]`,设备回复:

```json
{"Temp": 24.3, "Hum": 41.0}
```

### 上位机发送示例(Python)

```python
import psutil, serial, time

ser = serial.Serial("/dev/ttyACM0", 115200)
while True:
    vm = psutil.virtual_memory()
    line = f"MEM:{int(vm.percent)},MEMG:{int(vm.used/1e9)},TEMP:0,PWR:0\n"
    ser.write(line.encode())
    time.sleep(2)
```

`TEMP` / `PWR` 请按你的平台改写(例如用 `nvidia-smi` 读取 GPU 温度/功率)。

## 风扇控制逻辑

滞回控制防止继电器抖动:

- **开启**:`TEMP ≥ 60 °C` **或** `PWR ≥ 30 W`
- **关闭**:仅当 `TEMP ≤ 50 °C` **且** `PWR ≤ 20 W`
- 断连(无读数)时强制**关闭**。

屏幕上的向上箭头与风扇同步:绘制在仍高于关闭阈值的每一行;最后一个箭头在风扇停转的瞬间消失。风扇
启停会触发立即重绘(无视更新间隔)。

阈值都是 `dashboard.ino` 顶部的 `#define`,可按需调整。

## 编译与烧录

1. 安装 **Arduino IDE** 并添加 ESP32 板支持,选择 M5Paper 开发板。
2. 安装库:
   - **M5EPD**
   - **Adafruit SHT31 Library**(及其依赖 Adafruit BusIO)
3. 打开 `dashboard.ino` 并上传。
